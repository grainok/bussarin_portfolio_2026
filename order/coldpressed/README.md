# Morning Fresh Order Manager

Target URL: /order/coldpressed

Private two-person order tracking application. Do not deploy without server-side authentication, persistent database storage, backups, and verification.

Fields: order date, customer name, house number, product, quantity, amount, payment status, delivery status, notes.

Initial orders: 8 records (15–18 October 2026), including an unconfirmed 18 October order.

Never store passwords or customer records in a public repository.
